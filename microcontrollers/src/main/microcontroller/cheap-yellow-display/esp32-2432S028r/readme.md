
I first heard about the Cheap Yellow Dislpay (ESP32-2432S028R) from this [DeskBuddy project by LextZip](https://makerworld.com/en/models/2725262-deskbuddy-your-personal-dashboard#profileId-3019645).  Then I realized I wishI had known about way sooner.

Is is very robust with many uses.

The one I first used is [this one on Ali Express](https://www.aliexpress.us/item/3256810338829689.html).  There is a [nice little case](https://www.aliexpress.us/item/3256809664633579.html) there too.

The [source code for that DeskBuddy project is on Github](https://github.com/LextZip/Deskbuddy).  It has clock, weather, and timer widgets.  The 'Setup_Guide.md' file documents project setup.  

But here is a quick Arduino Setup break down:

    Rename the file .cpp to .ino

    Install the libraries mentioned in the Setup_Guide.md
        It seemed to work as is
            Did not have to update User_Setup.h under teh TFT-eSPI directory
    Update Wifi credentials
    
    It did not connect to a ‘newer’ Wifi router at my folks house.  So I’ll have to try one when I get home.
